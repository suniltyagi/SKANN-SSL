# SKANN-SSL — Full-Scale System: Diagnostics, Deployment & Deliverables

**Role:** Canonical operational contract for evaluating, deploying, and delivering the full SKANN-SSL system.

## Diagnostics (Locked)
- Embedding quality: redundancy index, dimensional utilisation, temporal stability.
- Robustness: augmentation stress tests, SNR sweeps, Doppler variation.
- Clustering: persistence, separability, and cluster signatures.

## Deployment & Export
- Canonical export format: **ONNX** (projection head removed).
- Targets: ARM Cortex-A, DSPs, NVIDIA Jetson, shore-side compute.
- Optional optimisations: quantisation, operator fusion, TensorRT.

## Dataset Strategy
- Two-phase SSL: synthetic pretraining → real-world SSL.
- Real datasets: NOAA, MBARI, JAMSTEC, DCLDE.
- Standardisation: fs = 32768 Hz, 1 s clips, RMS normalisation.

## Deliverables
- SSL-trained encoder weights.
- ONNX deployment package.
- Diagnostics reports and robustness plots.
- Embedding visualisations (PCA, UMAP, t-SNE).

## Authority
- Canonical for diagnostics, deployment, and deliverables.
- Does not override physics, DSP, synthesis, or architecture documents.
